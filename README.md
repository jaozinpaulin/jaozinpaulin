Sou estudante de Análise e Desenvolvimento de Sistemas com foco em Desenvolvimento Front-End moderno.

Atualmente, estou em um ritmo intensivo de evolução técnica, aplicando conceitos avançados de TypeScript estrito, Next.js (App Router), autenticação, gerenciamento de estado e consumo de APIs em projetos complexos e funcionais.

Meu objetivo é criar interfaces dinâmicas, acessíveis e de alta performance, me preparando para oportunidades no mercado em 2027.

### Projetos em Destaque

#### AniHub (Projeto Principal)
Plataforma web completa para streaming e gerenciamento de animes online.
- **Destaques:** Player de vídeo integrado, sistema de autenticação/login de usuários, armazenamento de dados em contas (animes salvos/favoritos, histórico), catálogo interativo e navegação dinâmica.
- **Tech Stack:** React.js, Tailwind CSS, React Router, REST APIs, Context API / State Management.
- [Ver repositório](https://github.com/jaozinpaulin/AniHub)

#### myLibrary
Sistema para gerenciamento de biblioteca pessoal e acervo digital de livros.
- **Destaques:** Cadastro e busca de livros, filtros dinâmicos, sistema de favoritos, opção de download e persistência via LocalStorage.
- **Tech Stack:** JavaScript ES6+, HTML5, CSS3, LocalStorage.
- [Ver repositório](https://github.com/jaozinpaulin/myLibrary-books)

#### myDarling
Interface temática interativa inspirada no universo de Darling in the Franxx com estética sci-fi e alta atenção aos detalhes visuais.
- **Destaques:** Layout responsivo, animações, estilo futurista e design focado em UI/UX.
- **Tech Stack:** HTML5, CSS3, JavaScript, UI/UX Design.
- [Ver repositório](https://github.com/jaozinpaulin/myDarling)
